# Collision_Risk_Metrics
This repository accompanies the paper submitted to ACC: "Expressiveness, Equivalence, and Uncertainty in Velocity Obstacles and Closest Point of Approach Metrics".

<pre>git clone https://github.com/eadietri/failureEstimation.git

</pre>

<pre>
python -m venv venv
</pre>

<pre>

<pre>
pip install -e .
</pre>
